# 🛠️ Skenario E: System Admin

**Peran:** Administrator Sistem
**Tujuan:** Memantau kesehatan sistem dan pengguna aktif.
**Akses:** Pilih role **System Admin** pada login Internal Team.

### Langkah-langkah Pengujian:

1.  **Login sebagai Admin:**
    *   Logout dari peran sebelumnya.
    *   Pada tab **Internal Team**, pilih Role: **System Admin**.
    *   Klik **Sign In**.
    *   ✅ *Verifikasi:* Masuk ke dashboard Admin (biasanya dengan tema lebih gelap/teknikal) dan melihat status "System Health".

2.  **Monitoring Sistem:**
    *   Periksa indikator "System Health" (harus 99.9%).
    *   Lihat jumlah "Active Users" saat ini.
    *   Verifikasi bahwa semua services operational.
