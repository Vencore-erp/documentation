# LEMBAR TUGAS PARTISIPAN (Task Sheet)
**Role:** OPERATOR & SUPERVISOR

---

Silakan ikuti instruksi di bawah ini secara berurutan. Jika Anda bingung, jangan ragu untuk bertanya "Apakah saya sudah selesai?" kepada Moderator.

### 🔐 TUGAS 1: Login & Explorasi
**Skenario:**
Anda adalah seorang **Operator Procurement** baru di perusahaan ini. Hari ini adalah hari pertama Anda menggunakan sistem.
**Instruksi:**
1.  Buka aplikasi.
2.  Login menggunakan akun **Operator**.
3.  Jelajahi Dashboard sebentar untuk memahami menu yang tersedia.

*(Beritahu Moderator jika Anda sudah ada di Dashboard)*

---

### 📝 TUGAS 2: Membuat Permintaan Pembelian (PR)
**Skenario:**
Departemen IT membutuhkan **5 unit Laptop High-End** segera karena ada proyek baru.
**Instruksi:**
1.  Buatlah dokumen **Purchase Requisition (PR)** baru.
2.  Isi departemen: **IT Department**.
3.  Tambahkan Item:
    *   Nama: **Laptop Gaming**
    *   Qty: **5**
    *   Harga Estimasi: **Rp 25.000.000**
4.  Submit PR tersebut untuk persetujuan.

*(Beritahu Moderator jika muncul pesan sukses)*

---

### 🤝 TUGAS 3: Manajemen Kontrak & Termin
**Skenario:**
Anda juga mengelola kontrak servis AC kantor. Anda ingin mengecek status pembayaran termin ke-2.
**Instruksi:**
1.  Buka menu **My Contracts**.
2.  Cari kontrak dengan vendor **"PT. Global Tech"**.
3.  Lihat detail kontrak tersebut.
4.  Cek apakah termin **"Q1 Service Delivery"** sudah bisa ditagihkan?
5.  Jika tombol **"Create Bill"** aktif, klik tombol tersebut.
6.  Submit Billing Request ke Finance.

*(Beritahu Moderator jika Anda sudah submit request)*

---

### ✅ TUGAS 4: Persetujuan Dokumen (Role Switch)
**Skenario:**
Sekarang anggap Anda adalah **Manoj (Supervisor)**. Anda mendapat email bahwa ada PR baru yang perlu diapprove.
**Instruksi:**
1.  **Log Out** akun Operator.
2.  Log In kembali sebagai **Supervisor**.
3.  Cari dokumen PR yang baru saja dibuat oleh Operator tadi.
4.  **Approve** dokumen tersebut.

*(Selesai. Silakan isi kuesioner)*
